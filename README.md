# 贴贴 · 记录型贴纸软件

把生活照片变成贴纸，按日期保存故事，再通过收藏、统计与每周回顾重新看见生活。

个人产品项目，包含 Web 业务页面和 Android 1.8.3 工程。功能包括本机主体抠图、手动圈选与校正、中文物品名称建议、描边、分区、收藏、热力图、回顾、照片导出、JSON 备份和两种 Android 桌面组件。

## 运行 Web 版

1. 准备本机模型与字体文件（见下方），它们不随源码仓库分发。
2. 在仓库目录执行 `node scripts/serve.mjs`，打开终端显示的本机网址。
3. Web 版按原有逻辑直接进入本机记录；构建的 Android 公开源码版演示邀请码为 `TTTTT-TTTTT-TTTTT-TTTTT`。这只是本机演示入口，不是线上身份验证。源码没有原内测邀请码表和旧账号公钥。

页面数据只保存在当前设备的浏览器中，照片不上传服务器。清理浏览器数据前请导出备份。

## 准备本机资源

已有原版贴贴的使用者，可从原版 `记录工具_开发版` 目录复制所需资源：

```powershell
./scripts/prepare-assets.ps1 -Source '原版记录工具_开发版的绝对路径'
```

若持有自己的完整迁移 ZIP，也可执行：

```powershell
./scripts/prepare-assets.ps1 -Archive '自己的完整迁移ZIP的绝对路径'
```

脚本只读取约定路径下的模型、运行时和字体文件；不会复制邀请码、账号文件、个人记录或安装包。资源仅写入本机被 Git 忽略的目录。

ONNX Runtime Web、U2NetP 与 MobileNetV2 提供推理和识别能力。来源及随原版保存的授权说明见 [web/离线模型/来源与许可.md](web/离线模型/来源与许可.md)。其中 MobileNet 权重的原始模型卡许可标为 `other`，所以本仓库不重新分发模型权重或字体；准备资源时请确认自己的使用权限。没有模型文件时，完整图片制作流程不可用。

## 构建 Android

环境：JDK 17、Android SDK 35、Gradle 8.10.2；Android Gradle Plugin 8.7.3。

```sh
node scripts/sync-android.mjs
cd android
gradle assembleDebug
```

同步脚本检查资源是否完整，将公开版页面与本机资源复制进 Android assets。仓库不包含签名密钥、Gradle Wrapper、APK 或 SDK。生成的调试版适合本机体验，不是应用商店发行包。

## 检查

资源准备后运行：

```sh
node web/记录_自检脚本.js
```

测试覆盖日期、贴纸记录、隐私分区、轮廓与描边、组件逻辑、备份结构、演示邀请码登录恢复和资源完整性。测试中的演示身份不代表原内测账号；逻辑回归不替代 Android 真机测试。

## 当前边界

- 隐私分区是查看锁，不是图片数据加密。JSON 备份包含图片，需自行保管。
- 没有云同步；同一演示邀请码在不同设备上不会共享记录。
- 自动抠图和分类可能出现错误，允许人工修改。
- iOS 工程尚未经过 Xcode 和真机验证，本次仓库只包含 Web 与 Android。
- 第三方文件遵循各自授权；本仓库尚未为原创代码指定再分发许可证。
