# 离线识别文件

这些文件随贴纸日历一同存放。运行时只从本文件夹读取，不请求网络，也不上传照片。

| 文件 | 用途 | 来源 |
|---|---|---|
| `ort.wasm.min.js`、`wasm-code.js`、`wasm-binary.js` | ONNX Runtime Web 1.22.0 的浏览器推理引擎 | [Microsoft ONNX Runtime](https://github.com/microsoft/onnxruntime)，MIT；许可见 `LICENSE-ONNX-Runtime.txt` |
| `model-u2.js` | U2NetP 主体抠图模型 | [rembg 提供的 U2NetP ONNX 权重](https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx)，上游 [U-2-Net](https://github.com/xuebinqin/U-2-Net)；许可见 `LICENSE-U2Net.txt` |
| `model-mobilenet.js` | MobileNetV2 0.35/96 图片类别建议 | [ONNX Community 转换模型](https://huggingface.co/onnx-community/mobilenet_v2_0.35_96)，原始模型见 [Google MobileNetV2](https://huggingface.co/google/mobilenet_v2_0.35_96) |
| `labels-zh.js` | 1000 类中文名称 | [Chinese-CLIP ImageNet 中文标签](https://github.com/OFA-Sys/Chinese-CLIP/blob/master/datasets/ImageNet-1K/label_cn.txt)，MIT；许可见 `LICENSE-Chinese-Labels.txt` |

`wasm-code.js` 将 ONNX Runtime 的模块文件转为可从 `file://` 页面加载的内嵌文本，并将默认 WASM 相对路径置空；`wasm-binary.js` 和两个 `model-*.js` 把原始二进制转为 Base64，没有改变模型权重。模型只会在选择照片后加载。

识物模型只覆盖 ImageNet 的 1000 种物体，类别建议可能不准确；详情页的中文名称和备注均可修改。抠图模型对低对比度、透明物体、多人或拥挤背景可能失误。`model-mobilenet.js` 所用权重的原始模型卡将许可标为 `other`；此包用于私人本机试用，公开再分发前需要复核权重许可。
